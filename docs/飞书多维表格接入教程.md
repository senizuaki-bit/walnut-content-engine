# 飞书多维表格内容发布接入教程

飞书多维表格是内容控制面。游戏运行时不直接查飞书，而是读取经过审核、校验、编译并带版本哈希的本地内容包。

## 1. 准备条件

- Windows 10/11。
- 一个可正常登录的飞书账号。
- 对目标 Base 的编辑权限；仅可查看权限不足以发布内容或回写课堂证据。
- Node.js 与 npm。虽然一键包自带运行内容引擎所需的便携 Node.js，但安装全局 `lark-cli` 仍需要 npm。

没有 Node.js 时，可在 PowerShell 中安装 LTS 版：

```powershell
winget install --id OpenJS.NodeJS.LTS --exact
```

安装后关闭并重新打开 PowerShell。

## 2. 安装并初始化 lark-cli

```powershell
npm install -g @larksuite/cli
lark-cli --version
lark-cli config init --new
```

最后一条命令会引导创建或绑定飞书开放平台应用。按浏览器页面完成设置后，授权 Base 能力：

```powershell
lark-cli auth login --domain base --no-wait --json
```

命令会返回验证地址和设备码。打开该地址，输入设备码并确认授权；随后执行：

```powershell
lark-cli auth status --json --verify
lark-cli whoami
```

`user.status` 应为 `ready`，`tokenStatus` 应为 `valid`。

## 3. 选择 Base

项目预置的演示 Base：

```text
https://hcn3j6gp4127.feishu.cn/base/A7IcbT6oHaUKXIsAjHrcrlhinwg
```

有两种方式：

### 方式 A：直接使用演示 Base

仓库维护者需要先把你的飞书账号添加为可编辑成员。打开上面的链接确认能看到六张表：知识概念、误区库、内容单元、提示策略、课堂证据、实验决策。

### 方式 B：复制到自己的飞书

有源 Base 访问权限时执行：

```powershell
lark-cli base +base-copy --base-token A7IcbT6oHaUKXIsAjHrcrlhinwg --name "核桃世界-内容引擎副本" --time-zone Asia/Shanghai --as user --format json
```

复制后打开命令返回的新 Base。因为复制后的表 ID 和记录 ID 会变化，下一步必须重新配置，不能手改猜测 ID。

## 4. 自动识别并写入项目配置

双击一键包根目录的：

```text
配置飞书多维表格.bat
```

粘贴目标 Base 链接。脚本会以只读方式完成：

1. 验证当前飞书登录状态。
2. 从链接解析 Base token。
3. 按表名自动找到内容单元、误区库、提示策略和课堂证据表。
4. 按“单元ID”找到 `UNIT-DATA-GARDEN-LOOP` 的记录 ID。
5. 更新本机 `content-engine/feishu/publish-config.json`。

它不会修改云端记录，也不会把 OAuth 凭据写入项目。

## 5. 只读验收

双击：

```text
验证飞书多维表格连接.bat
```

成功标志：

```text
WALNUT_FEISHU_CONNECTION_OK
```

该检查只读取 Base、表和目标内容单元，不会写入任何记录。

## 6. 演示内容发布联动

1. 在飞书“内容单元”表找到 `UNIT-DATA-GARDEN-LOOP`。
2. 先把版本号升一级，再修改允许的目标数或提示策略。
3. 勾选“发布请求”。
4. 运行 `发布内容引擎.bat`，或保持 Demo 启动器的发布监听运行。
5. 发布器读取内容、执行契约校验和自动测试，编译新的 Godot/AI 内容包，再把发布结果、哈希和时间回写飞书。
6. 回到游戏重新进入关卡，顶部版本和目标数会更新。

游戏结算后的结构化学习事件会由本地服务聚合，再幂等回写“课堂证据”表。自动化测试记录会明确标记为“自动化QA”，不会冒充真实儿童数据。

## 权限与故障

- `lark-cli` 找不到：安装后新开终端，确认 npm 全局目录已加入 `PATH`。
- 登录有效但 Base 无权限：让 Base 所有者把当前 `whoami` 对应用户加入为编辑成员。
- 缺少表：复制的 Base 结构不完整；需要保留上述六张表和对应字段。
- 找不到单元记录：确认“内容单元”表的“单元ID”字段存在，且包含 `UNIT-DATA-GARDEN-LOOP`。
- 发布时返回写入权限错误：只读检查不会发现记录级编辑限制；请检查 Base 高级权限与字段权限。

本项目不会在仓库中保存飞书 access token。授权由 `lark-cli` 在本机管理，可用 `lark-cli auth logout` 清除。
