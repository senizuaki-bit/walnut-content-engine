# 火山引擎方舟与 Seedream 接入教程

火山引擎只用于 AI 世界工坊：豆包文本/视觉模型生成并复核受限世界文案，Seedream 生成皮肤素材。它不参与游戏判题或通关。

## 1. 开通服务与模型

1. 注册并登录火山引擎账号，完成平台要求的认证和计费设置。
2. 进入 [火山方舟控制台](https://console.volcengine.com/ark/region:ark+cn-beijing/)。
3. 在模型管理中确认账号可调用文本/视觉模型和图片生成模型。
4. 在 [API Key 管理](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey) 创建 Key。

本项目当前默认模型：

```text
文本与视觉：doubao-seed-2-0-pro-260215
图片生成：doubao-seedream-5-0-lite-260128
```

如果控制台为你的账号展示了不同的可调用模型 ID，请在配置向导中输入控制台显示的 ID。接口基地址和模型可用性以 [火山方舟官方文档](https://www.volcengine.com/docs/82379/seedream?lang=zh) 为准。

## 2. 写入本机配置

双击一键包根目录的：

```text
配置火山引擎.bat
```

隐藏输入 API Key，然后确认或修改文本、视觉、图片模型 ID。配置写入：

```text
xiao-hetao-ai-server/.env
```

脚本只更新火山引擎和世界工坊相关键，会保留 DeepSeek 配置。

默认接口：

```env
ARK_TEXT_API_URL=https://ark.cn-beijing.volces.com/api/v3/chat/completions
ARK_VISION_API_URL=https://ark.cn-beijing.volces.com/api/v3/chat/completions
SKIN_IMAGE_API_URL=https://ark.cn-beijing.volces.com/api/v3/images/generations
```

## 3. 验证配置和连接

只检查本地配置，不联网、不计费：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify-volcengine.ps1 -ConfigOnly
```

双击 `验证火山引擎连接.bat` 会先征求确认，再发起一次很小的文本请求。成功标志：

```text
WALNUT_VOLCENGINE_TEXT_OK
```

该检查只验证 Key、文本接口和文本模型。Seedream 图片权限需要通过下一节的真实生成验证；文生图会产生更明显的费用。

## 4. 先跑离线工坊

下面的命令不调用任何模型，也不计费，用于确认本地生成、图片占位、契约校验和 Godot 候选冒烟链路：

```powershell
cd .\content-engine
& "..\tools\node\node.exe" .\scripts\generate-skin-candidate.mjs --theme=海底 --version=0.8.2 --mock
```

## 5. 真实生成世界皮肤

确认账户余额和模型权限后运行：

```powershell
cd .\content-engine
& "..\tools\node\node.exe" .\scripts\generate-skin-candidate.mjs --theme=海底 --version=0.8.2
```

一次候选通常会调用文本、视觉和多张图片生成。程序默认断点续跑，已经成功的检查点和原图不会重复计费。不要随意添加 `--fresh`；它会强制全部重生。

生成后仍需要人工在飞书查看候选预览，勾选候选审核、安全审核和发布请求。发布器会再次执行素材尺寸、背景比例、调色板、感知哈希去重和 Godot 冒烟检查。

## DeepSeek 后备

世界文案默认使用火山方舟；当方舟文本模型暂不可用且已配置 DeepSeek 时，可按 `.env` 中的供应商顺序回退：

```env
GENERATION_TEXT_PROVIDER=ark
GENERATION_TEXT_FALLBACK_PROVIDER=deepseek
```

视觉审核和图片生成不会自动改用 DeepSeek。

## 常见错误

- `401`：Key 不正确、被禁用或复制不完整。
- `403`：账号、项目或 API Key 没有该模型权限。
- `404`：模型 ID/接入点 ID 不存在，或区域/接口地址不匹配。
- `429`：配额或并发限制，稍后重试并保留检查点。
- 图片生成超时：不要立即 `--fresh`；原命令重跑会从检查点继续。
- 视觉审核提示模型未开通：确认 `ARK_VISION_MODEL` 权限；仅做离线结构验证时可临时设 `GENERATION_VISION_REQUIRED=false`，生产发布不建议关闭。

API Key 不要放进截图、录屏、命令参数、Git 提交或飞书单元格。需要撤销时到方舟控制台删除 Key，并重新运行配置向导。
