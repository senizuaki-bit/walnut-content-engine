# Plan A · 核桃世界：数据花园 Windows 一键联动包

联动包版本：`0.8.1`

内置发布内容版本：`0.8.0`

本包对应 Plan A「核桃世界」，包含内容引擎和“数据花园”可运行游戏。提交材料中的《提案报告－核桃守卫战》属于未纳入实现的独立 Plan B，不是本 Demo 的关卡或子模块。

## 直接运行

1. 完整解压本压缩包，不要直接在压缩软件内运行。
2. 双击根目录的 `运行数据花园Demo.bat`。
3. 启动器依次准备内容发布监听、本地 AI 安全代理和 Godot 游戏；关闭游戏后会清理本次启动的后台进程。

包内已经带有 Godot 4.5.2 和 Node.js 便携环境。没有任何在线账号或 API Key 时，游戏仍会读取包内已经发布的内容版本并正常运行，小核桃会使用内置五级提示。

## 按需启用在线能力

| 能力 | 操作入口 | 详细教程 |
|---|---|---|
| 小核桃 DeepSeek 个性化提示 | `配置DeepSeek密钥.bat` → `验证DeepSeek连接.bat` | `DeepSeek接入说明.md` |
| 飞书改内容、审核、发布与证据回写 | `配置飞书多维表格.bat` → `验证飞书多维表格连接.bat` | `飞书多维表格接入教程.md` |
| 火山方舟文案/视觉与 Seedream 皮肤生成 | `配置火山引擎.bat` → `验证火山引擎连接.bat` | `火山引擎接入教程.md` |

第一次使用建议先阅读 `接入配置总指南.md`。在线能力互不强制依赖，不需要为了运行 Demo 一次性配置全部服务。

## 内容引擎与游戏联动

`飞书内容控制面 → 内容校验/编译 → content/generated 内容包 → Godot 动态读取 → 学习事件聚合 → 飞书课堂证据`

- 双击 `发布内容引擎.bat` 可手动执行一次飞书发布；运行 Demo 时也会启动发布监听。
- 飞书未登录或不可用时，不会破坏已发布的本地内容包。
- Godot 不保存任何服务商 API Key；DeepSeek 只改写提示表达，火山引擎只生成受限世界文案和皮肤。
- 判题、通关、程序执行、诊断、内容哈希和安全边界都由本地确定性代码控制。

## 包内重要文件

- `my_topdown_game-main/`：Godot 4.5 游戏工程与可运行内容。
- `content-engine/`：内容契约、校验、编译、飞书发布和 AI 世界工坊。
- `xiao-hetao-ai-server/`：只监听本机的 AI 安全代理。
- `tools/`：便携 Node.js 与 Godot。
- `内容引擎使用说明.md`：内容引擎设计和日常使用。
- `AI世界工坊与迁移变式使用说明.md`：世界皮肤与迁移变式完整流程。

## 安全提醒

API Key 只保存在本机 `xiao-hetao-ai-server/.env`。不要上传、转发或录屏展示该文件。飞书 OAuth 凭据由 `lark-cli` 管理，不写入本项目。
