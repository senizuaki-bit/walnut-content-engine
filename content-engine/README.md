# 核桃编程内容引擎 MVP

本目录把“数据花园”从一次性关卡，抽象为可持续生产的“知识—体验—评价单元”。

## 现在怎么用

日常使用不需要写 JSON，也不需要改 Godot 代码：

1. 打开飞书 Base 的“内容单元”表，找到 `UNIT-DATA-GARDEN-LOOP`。
2. 把“版本”从当前版本升一级，例如 `0.5.0` 改成 `0.6.0`；修改“主任务目标数”或“迁移目标数”（允许 2—8）。提示文案在“提示策略”表维护，答案级模板可用 `{main_target}` 引用主任务目标数。
3. 勾选“发布请求”。运行 Demo 时发布器每 3 秒检查一次；也可双击根目录的 `发布内容引擎.bat` 立即发布。
4. 看“发布结果”：成功后“发布请求”会自动取消，“发布时间”“已发布哈希”“自动测试通过”会自动更新。重新进入关卡后，画面顶部会显示“内容引擎 · 版本 · 主任务/迁移目标数 · 哈希”。

学生完成一局后，事件服务会聚合无提示迁移、反事实、求助、概念显形、Boss Debug 和主动探索；启动器会自动把结算记录写回“课堂证据”表。测试局一律标记为“自动化QA”，不会冒充儿童学习数据。

这就是内容引擎在 Demo 里的可感知作用：同一套教学模板和游戏代码不变，教研只改飞书中的版本、目标数与提示策略，就能得到经过校验的新关卡内容，并把该版本的实际学习证据收回来。

飞书多维表格是内容控制面：教研、策划、设计和运营在其中维护概念、误区、内容单元、提示策略、课堂证据和实验决策。Godot 与 AI 服务不在课堂运行时直接查询飞书，而是消费经过审核、校验和编译的不可变内容包。

## 核心闭环

1. 发现：从课堂事件、教师观察和孩子反馈中发现卡点与惊喜机会。
2. 建模：定义认知本质、典型误区、掌握标准和安全边界。
3. 编译：把知识映射为世界机制、任务链、提示树、迁移任务和惊喜反馈。
4. 验证：执行结构校验、自动测试、教研审核、安全审核和小规模试教。
5. 决策：按“趣味 × 效果”的二维证据决定扩产、改版或淘汰，避免用单一综合分掩盖问题。

## 系统边界

- 飞书 Base：低频内容运营、审核、协作、聚合证据和实验决策。
- 内容编译器：读取一个获批版本，生成带哈希的 Godot 与 AI 配置。
- Godot 客户端：只执行已发布配置，不保存服务商密钥，不让模型替学生写核心代码。
- AI 安全代理：读取同版本提示策略，根据结构化状态生成最小必要帮助，并做泄题、格式和隐私校验。
- 事件与分析：Godot 本地留痕并异步上传，服务端保存原始 JSONL、聚合会话证据并生成飞书 outbox；飞书不承载高频原始埋点。

## 已实现的运行内核

- `Sequence / Repeat / Action` 统一程序 IR；当前积木和未来受限 C 代码可以投影到同一结构。
- 最大 100 步的安全解释器；不执行任意 C、文件、网络或操作系统指令。
- `TEMPLATE-REPEAT-TARGETS` 教学模板，以及“光种生长”“陌生巡检器”两个世界皮肤。
- 每一步输出节点 ID、循环轮次、动作、目标和状态变化组成的执行轨迹。
- 确定性诊断：缺少循环、空循环体、动作错误、次数不足、次数过多、成功和执行步数超限。
- Godot 将诊断 ID、轨迹摘要和内容版本传给小核桃；AI 只负责适龄表达。
- 课堂事件以 JSONL 写入本地 `user://data_garden_learning_events_v1.jsonl`，同时异步发送到事件服务，并携带 `event_schema_version/unit_id/version/content_hash`。
- 服务端按会话聚合反事实、无提示迁移首过、概念显形、Boss 调试、复练、惊喜后探索等证据，并生成幂等飞书回写载荷。

## 最小内容单位

一个内容单元必须同时包含：

- 一个明确的编程概念与认知本质；
- 可观察的典型误区；
- 由代码真实控制的世界机制；
- 感知、预测、编排、执行追踪、反事实、迁移、抽象命名和 Debug 任务链；
- 分级提示策略与答案暴露边界；
- 由学生代码触发的因果惊喜；
- 无提示迁移、延迟复测和解释证据；
- 自动测试、教研审核和安全审核状态。

## 趣味 × 效果决策

主效果指标使用“无提示迁移首过率”，而不是主任务通关率。延迟复测与解释通过作为第二层证据。

主趣味指标使用“惊喜后主动继续探索”，辅以可选探索率和孩子 1–5 分即时反馈。视觉播放完成、停留时长或点击数不能单独等同于喜欢。

决策矩阵：

| 趣味 | 效果 | 决策 |
|---|---|---|
| 高 | 高 | 扩产为模板，并测试跨知识点复用 |
| 高 | 低 | 保留世界机制，重做认知映射、提示与迁移 |
| 低 | 高 | 保留教学骨架，重做惊喜时机与世界回应 |
| 低 | 低 | 淘汰，不继续换皮 |

所有扩产同时满足护栏：45 分钟可控、教师可干预、AI 不泄题、儿童隐私最小化、安全事件为零。

## 本地命令

```powershell
& "..\tools\node\node.exe" ".\scripts\validate-content.mjs" ".\source\data-garden-loop.json"
& "..\tools\node\node.exe" ".\scripts\compile-content.mjs" ".\source\data-garden-loop.json"
```

编译产物位于 `generated/godot/` 与 `generated/ai/`。它们带有同一个 `content_hash`，课堂事件必须同时记录 `unit_id`、`version`、`content_hash` 和实验变体，才能把学习结果准确归因到某个内容版本。
