# 核桃编程 · 数据花园 Demo

双击工作区根目录的 `运行数据花园Demo.bat` 即可开始。项目已附带 Godot 4.5.2 便携运行时，不需要安装开发环境。

## 操作

- 移动：`WASD` 或方向键
- 观察/交互：`E` 或回车
- 预测：在中央控制台选择一种结果
- 编排：把“生长/巡检”拖进橙色重复结构；单击动作也提供无障碍替代操作
- 调整次数：点击橙色结构，或按 `3 / → / ↑`
- 运行：点击运行按钮，或按回车
- 请求提示：`H` 或点击小核桃出现时的“提示 H”
- 可选探索：迁移阶段靠近左侧记忆晶体，按 `E`
- 完成后重玩：`R`

鼠标始终使用系统光标，不会因进入 Demo 而隐藏。

## 完整学习链

1. **感知规律**：四颗光种保持休眠，小核桃不预先说“循环”。
2. **预测结果**：玩家预测只执行一次 `生长` 会发生什么，再让世界验证；一次只亮一颗。
3. **编排程序**：自然语言目标先出现，随后把“生长”拖进“重复”结构并修改次数。
4. **观察执行**：程序逐行高亮，连接线、当前光种和代码轨迹同步发光。
5. **修改验证**：成功运行 4 次后，必须把 4 改成 3；最后一颗会明确保持休眠。
6. **迁移应用**：不提示结构名称，独立控制陌生巡检器检查 4 个目标。
7. **抽象命名**：小核桃最后才说明“这个结构叫循环”，并显示第四层 C 语言代码：

```c
for (int i = 0; i < 4; i++) {
    grow();
}
```

代码按四层逐步显形：**世界行为 → 自然语言指令 → 积木/流程结构 → C 语言代码**。

## 小核桃 AI

小核桃只承担四项职责：新手引导、分级提示、学习反思、长期陪伴与成长记录。它不是泛化聊天机器人。

- 游戏本地状态机负责全部判题、执行轨迹和过关结果；DeepSeek 不能决定正确与否，也不能替玩家修改程序。
- AI 只读取年龄段、当前阶段、当前程序、最近一次修改、确定性错误类型、尝试次数和提示等级等结构化状态。
- 提示阶梯依次为：确认目标 → 观察世界偏差 → 指出代码区域 → 给部分结构/轨迹 → 展示完整答案并标记复练。
- 第五级只展示答案，不会自动替玩家把次数改成 4；结算会记录“需要复练”。
- 无 Key、断网、超时、余额不足或限流时，会自动使用同一规则的本地提示。

配置方法见工作区根目录的 `DeepSeek接入说明.md`。

## Debug Boss

守门者不再是传统选择题。初始缺陷程序会在“护盾 → 弱点 → 护盾 → 弱点”四拍中每拍攻击：

- 玩家先运行错误程序，看到第 1、3 拍攻击被护盾反弹，伤害被回滚。
- 随后把攻击条件改为“仅在弱点暴露时攻击”。
- 程序重新逐拍执行；护盾阶段被条件安全跳过，两次攻击命中弱点后才算通关。

小核桃助力只回放执行轨迹，不排除答案或代替修改。

## 一节课建议节奏

- 0–5 分钟：进入世界、移动并认识小核桃。
- 5–13 分钟：观察四颗光种、做单次生长预测。
- 13–23 分钟：拖入动作、调整次数、逐行观察世界执行。
- 23–29 分钟：完成 4→3 的反事实实验并讨论证据。
- 29–35 分钟：自由谜题与四目标陌生迁移。
- 35–39 分钟：概念命名与 C 语言代码显形。
- 39–44 分钟：守门者 Debug 战。
- 44–45 分钟：阅读学习证据与复练标记。

自动化成功标志：`DATA_GARDEN_SMOKE_OK`、`XIAO_HETAO_SERVER_TEST_OK`、`XIAO_HETAO_GODOT_AI_OK`。
